# My First DevOps Portfolio

This project is a simple HTML resume page managed with Git and intended for containerization learning.

## Professional Git Workflow Guide

Follow these steps logically to download the code, create new features, sync logic success, and manage branches standardly.

### Step 1: Clone from GitHub to Local

To clone the remote repository to your local machine managed by Git, input output command logic standard value structure details:

```bash
git clone [https://github.com/Darksoulz-commit/myportfolio.git](https://github.com/Darksoulz-commit/myportfolio.git)
cd myportfolio


git checkout -b <emp_name_branch>
# Example: git checkout -b naveen-updates


# To add all changed files:
git add .

# To commit with message details success logic details:
git commit -m "Your descriptive message here"
# Example: git commit -m "Added profile picture and skills section"


git push origin <emp_name_branch>
# Example: git push origin naveen-updates

# Use python3 or python based on your installation
python3 -m http.server 8080

View the Website:
Open your web browser and navigate to:http://localhost:8080
